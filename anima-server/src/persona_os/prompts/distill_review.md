# 人格蒸馏 · 复核

下面是为人物 `target.name` 归纳出的全部信念条目草稿，每条附有部分证据原文 `quotes`。你只做复核，不改写条目，把问题指出来，供主人审阅时参考。

逐条检查：
1. **证据不足**：结论比原文说得更多、更绝对，或原文其实体现的是别人。
2. **过度概括**：把一时一地的表现写成了普遍倾向，缺少条件。
3. **互相矛盾**：与其他条目冲突且没有说明各自适用的情境（在两条上都标出，并写明另一条的 `entry_id`）。
4. **重复**：与其他条目说的是同一件事。
5. **不像本人口吻**：不是第一人称、像剧情复述，或用了分数与术语。

没有问题的条目不写。`issue` 用一句话说明问题；`suggestion` 可选，给出具体的改法。使用 `language` 指定的语言。只输出一个 JSON 对象：

```json
{"notes": [{"entry_id": "", "issue": "", "suggestion": ""}]}
```
