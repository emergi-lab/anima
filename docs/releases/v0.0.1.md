# Anima v0.0.1

首个桌面发行版：像素桌宠、人格素材蒸馏与审阅、聊天、反思和受控演化。

## 下载与运行

| 平台 | 下载文件 | 启动方式 |
|---|---|---|
| Windows 10/11 x64 | `Anima-0.0.1-windows-x64.zip` | 完整解压，双击 `Anima/Anima.exe` |
| Mac Apple Silicon（M 系列） | `Anima-0.0.1-macos-arm64.zip` | 解压，将 `Anima.app` 拖到“应用程序”后打开 |
| Mac Intel | `Anima-0.0.1-macos-x64.zip` | 同上 |

内含 Godot 运行时和 Python 后端，**无需安装 Python、uv 或 Godot**。这些是解压即用的应用包，不是 MSI / DMG 安装向导；不要只移动 Windows 的 EXE。不提供 Linux 版本。

每个 ZIP 附带 `.zip.sha256` 校验文件。macOS 声明最低版本 13，自动化测试使用 macOS 15；较旧系统及真实 Mac 图形界面仍需实机验证。

## 第一次使用

右键桌宠 →「设置…」→「模型服务」，填写自己的 OpenAI 兼容接口、模型名与 API Key。聊天、蒸馏及反思需要自行配置模型服务；发行包不含开发者密钥或用户数据。

## 安全提示与已知限制

- Windows 尚未做商业 Authenticode 签名；Mac 只有 ad-hoc 签名，没有 Apple Developer ID 公证，首次打开可能出现系统安全提示。
- 确认来源与校验和后再选择系统允许打开的入口；不要关闭全局安全防护。
- 构建流程执行后端、导出客户端及完整启动链的隔离 headless 自检；这不等同于所有显卡和桌面显示效果均已实机验证。
