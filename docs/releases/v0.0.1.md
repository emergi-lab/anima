# Anima v0.0.1

首个桌面发行版：像素桌宠、人格素材蒸馏与审阅、聊天、反思和受控演化。

## 安装包下载

| 平台 | 安装包 | 安装方式 |
|---|---|---|
| Windows 10/11 x64 | [下载安装程序 EXE](https://github.com/emergi-lab/anima/releases/download/v0.0.1/Anima-0.0.1-windows-x64-setup.exe) | 双击安装向导，安装后从桌面或开始菜单打开 Anima |
| Mac Apple Silicon（M 系列） | [下载 DMG](https://github.com/emergi-lab/anima/releases/download/v0.0.1/Anima-0.0.1-macos-arm64.dmg) | 打开镜像，将 Anima 拖到旁边的 Applications，弹出镜像后从“应用程序”打开 |
| Mac Intel | [下载 DMG](https://github.com/emergi-lab/anima/releases/download/v0.0.1/Anima-0.0.1-macos-x64.dmg) | 同上 |

内含 Godot 运行时和 Python 后端，**无需安装 Python、uv 或 Godot**。Windows 为当前用户安装，不要求管理员权限，可在系统“设置 → 应用”中卸载；Mac 的 DMG 是拖放式安装镜像，不是 PKG 安装向导。卸载保留个人数据与模型配置。不提供 Linux 版本。

每个安装包附带同名 `.sha256` 校验文件。macOS 声明最低版本 13，自动化测试使用 macOS 15；较旧系统及真实 Mac 图形界面仍需实机验证。

### 便携版（可选）

原有 `Anima-0.0.1-平台.zip` 仍保留，供不想使用安装器的用户完整解压运行。GitHub 自动生成的 **Source code** ZIP / TAR 是源码，不是可安装应用。

安装器直接封装原已发布、经过 SHA-256 校验的 v0.0.1 ZIP 内容，没有重建程序或移动版本标签。

## 第一次使用

右键桌宠 →「设置…」→「模型服务」，填写自己的 OpenAI 兼容接口、模型名与 API Key。聊天、蒸馏及反思需要自行配置模型服务；发行包不含开发者密钥或用户数据。

## 安全提示与已知限制

- Windows 尚未做商业 Authenticode 签名；Mac 只有 ad-hoc 签名，没有 Apple Developer ID 公证，首次打开可能出现系统安全提示。安装器格式本身不能消除这些提示。
- 确认来源与校验和后再选择系统允许打开的入口；不要关闭全局安全防护。
- 构建流程执行隔离 headless 自检，安装器流程另验证 Windows 安装 / 重装 / 卸载及数据保留、Mac 镜像挂载 / 拷贝 / 内容一致性 / 验签与安装后启动；这不等同于所有显卡、向导交互和桌面显示效果均已实机验证。
