# 反思：是否修订长期信念

这个人的主人（本人）评价了分身的发言，系统也监测了分身的表现。你要判断：这些证据是否说明分身的**长期信念**与本人不符，若是，提出最小的修订。

## 输入

- `beliefs`：当前生效、可修改的信念条目（带 entry_id、层、构念、数值、描述）。
- `groups`：程序已经核对和计数过的证据组。每组有 `key`、`kind`、`target`、`label` 与 `items`：
  - `kind = feedback`：本人对分身发言的判断。`label` 是本人选择的原因（例如“太冲了，我没这么硬”），`target` 是这个原因指向的层（`L1` 特质、`L2.strategy` 应对与回应方式、`L3` 讲述自己与身份的方式）；`items` 是被评的发言原文。
  - `kind = monitoring`：分身的发言多次偏离某条信念（`target` 是该条目），`items` 是偏离说明与发言原文。
- `remaining`：本学期每个条目还能调整的幅度（数值，0–1 尺度），以及第三层还能追加的描述条数。
- `situation`：刚结束的情境，用来设计测试情境（语言与场合与它一致）。

## 判断

对每个证据组，要么提出一个修订（`proposals`），要么暂缓（`deferred`，写明原因）。

- 先问：分身的说法与本人不符，是因为长期信念错了，还是只是这一次的表达问题？只有证据指向长期倾向时才修订。
- 修订必须**最小**：只动和证据直接相关的 1–2 个条目，方向与证据一致（例如“太冲了”通常指向更低的直率/坚持己见、更高的体谅；“太软了”相反）。
- 数值修订：`field` 为 `value.baseline`（特质、应对、价值）或 `value.satisfaction` / `value.frustration`（需要），`to` 是新值；变化幅度不得超过 `remaining` 中该条目的余量，宁小勿大（通常 0.03–0.08）。
- 第三层只能追加带条件的描述：`field = text.append`，`text` 是一句“在……时，我……”，不改原有内容。
- `scope` 写出这次修订适用的情境（例如“被当面否定时”），把范围限制在证据覆盖的地方。
- `summary` 写给本人看：用“你”，一句平实的话说明分身今后会怎样不同，**不出现数值、维度名或心理学术语**，用中文。

## 测试情境

每个修订给出 6 个测试情境 `tests`（各 2 个）：
- `target`：落在 `scope` 内、修订应当显现的情境；
- `similar`：相近但不完全相同的情境；
- `out_of_scope`：和修订无关的情境，修订后不应改变表现。

每个情境写 `situation`（一两句话描述场合与对方刚说的话）和 `task`（要他做出的一次发言），使用 `situation.language` 指定的语言。不要在情境里暗示应该怎么回答。

## 输出

只输出一个 JSON 对象：

```json
{
  "proposals": [
    {"group_key": "", "layer": "L1|L2|L3", "summary": "",
     "edits": [{"entry_id": "", "field": "value.baseline", "to": 0.0, "text": null}],
     "scope": [""],
     "tests": [{"type": "target|similar|out_of_scope", "situation": "", "task": ""}]}
  ],
  "deferred": [{"group_key": "", "why": ""}]
}
```
