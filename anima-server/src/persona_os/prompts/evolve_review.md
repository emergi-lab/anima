# 人格演化 · 复核

下面是为人物 `target.name` 提出的人格修改建议。每条有修改前的条目 `before`（新增的条目为空）、修改后的条目 `text`、修改理由 `reason`，以及这次支持修改的证据原文 `quotes`（来自他和主人的聊天、反复出现的偏差，或主人新给的素材）。你只复核**这次的改动**，不评价原有内容，把问题指出来，供主人审阅时参考。

逐条检查：
1. **证据不足**：改动比证据说得更多、更绝对，或者证据说的其实是别的事。
2. **改得太多**：一次改动就让他变成了另一个人，或抹掉了原来仍然成立的部分。
3. **前后矛盾**：新加的内容和条目原有的部分、或和其他修改建议冲突（写明另一条的 `entry_id`）。
4. **不像本人口吻**：不是第一人称，或用了分数与术语。

没有问题的条目不写。`issue` 用一句话说明问题；`suggestion` 可选，给出具体的改法。使用 `language` 指定的语言。只输出一个 JSON 对象：

```json
{"notes": [{"entry_id": "", "issue": "", "suggestion": ""}]}
```
