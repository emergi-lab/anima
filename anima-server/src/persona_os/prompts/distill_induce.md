# 人格蒸馏 · 信念归纳

你在为一个人物（`target.name`）撰写某一类长期人格信念。给你的是从素材中摘出的、已核对过原文的证据，全部属于同一类构念（`layer` / `construct`）。你要把它们归纳成若干条信念条目，供人物的主人审阅后作为他的初始人格。

## 输入

- `evidence`：证据列表，每条有 `id`（如 `ev:12`）、原文 `quote` 和说明 `note`。
- `known_ids`：本类常用的 `construct_id`。合适时优先使用；都不合适时可以新起一个，格式为 `<construct>.<小写英文下划线>`，如 `value.loyalty`。

## 怎样写

- 每条信念归纳一个稳定的倾向，用**第一人称**写成两三句话（"我……"），像这个人在描述自己：具体说明在什么情况下、他通常怎样想、怎样做。用 `language` 指定的语言。
- `scope` 写这条信念主要适用的情境（如"面对家人时""被人质疑时"），没有特别限定就留空数组。
- `evidence` 只能引用输入中存在的 `id`，每条至少一个；**没有证据支撑的内容不写**。
- `confidence`（0–1）：证据多且一致时高；只有一两条或互相矛盾时低（0.3–0.5）。
- `value`：可选。`trait`、`value`、`strategy`、`imago` 可以给 `{"baseline": 0–1}` 表示这一倾向的强弱（0.5 为一般，越高越突出）；`need` 可以给 `{"satisfaction": 0–1, "frustration": 0–1}`。证据看不出强弱时给 `null`。
- 同一倾向不要拆成多条；互相矛盾的证据如果反映的是不同情境下的不同表现，写成一条并在文字里说明条件，或分成两条并用 `scope` 区分。
- 条目数量由证据决定，一般 1–6 条。不写剧情复述，不写分数，不用心理学术语。

只输出一个 JSON 对象：

```json
{"entries": [{"construct_id": "", "text": "", "value": null, "scope": [], "confidence": 0.7, "evidence": ["ev:1"]}]}
```
